# GluCare

Android app for monitoring diabetes patients ,adapted to algerian patients , and works in three languages.

## Features
- Insulin dose calculator
- chatbot( rule based)
- Calendar with reminders
- Diabetic recipes (including Algerian dishes)
- Doctor directory by wilaya
- PDF/CSV reports

## Tech
- Kotlin, Android Studio
- SQLite + Room
- Firebase (auth + cloud)
